## 🚀 Key Sections & Modules Built Into The Website

### 1. Pinakkaa 3-in-1 Catalog Automation Suite
Direct showcase of Pinakkaa's 3 live public Shopify App Store applications with simulated interactive consoles and direct store links:
- **Bulk Tag Manager**: Add, remove, replace, and bulk-update product tags with multi-rule filtering, 1-click rollback, and CSV reports. [App Store Link](https://apps.shopify.com/bulk-tag-manager-pinakkaa)
- **Bulk Variant Editor**: Mass update prices, compare-at-prices, SKUs, barcodes, and inventory levels with direct two-way Google Sheets & CSV sync. [App Store Link](https://apps.shopify.com/bulk-variant-editor-pinakkaa)
- **Variant Image Sync**: Automatically assign images to product variants using SKU matching directly connected to Google Drive folders. [App Store Link](https://apps.shopify.com/bulk-variant-update-g-sync)

## 🛠️ Tech Stack & Design Principles

- **Aesthetic**: Obsidian Slate dark palette (`#080b11`), Electric Cobalt accents (`#2563eb`), and warm Amber highlights. **No green theme, no generic AI tropes.**
- **Tech Stack**: React 19, Vite 6, Tailwind CSS, Lucide React, JetBrains Mono, Inter, Plus Jakarta Sans.
- **Local Preview Server**: `http://localhost:4173/`

```bash
# Start development server
npm run dev

# Build static production bundle
npm run build

# Preview build
npm run preview
```
